# Schoolnet Project Instructions

Before making changes, read:

- docs/schoolnet-redesign-implementation-prompt.md
- docs/schoolnet-deployment-plan-implementation.md

Treat these documents as the product, UX, content,
architecture, and deployment source of truth.

Rules:

- Build a modern Schoolnet India website.
- Schools are the primary commercial audience.
- Student experience should be highly engaging.
- Preserve verified Schoolnet facts.
- Never invent Schoolnet statistics.
- Use XX, XX+, or "To be confirmed" where data is unavailable.
- Use mock authentication for Student, Teacher, and School Admin.
- Keep infrastructure extremely low-cost.
- Target Cloudflare for initial deployment.
- Implement working UI, not just recommendations.
- Run lint, type checks, and build before completing major work.
